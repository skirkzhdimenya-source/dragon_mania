# Каталог построек Dragon Mania Legends / DragonML

Источник: извлечённый из игрового каталога `files/data/structures.json`.

## Файлы
- `structures.json` — оригинальные 954 записи без потери полей.
- `structures_catalog.csv` — полный табличный каталог с UID, внутренним ID, параметрами и локализованными именами EN/RU.
- `event_generators.csv` — все 158 записей с `OBJECT_TYPE = EVENT_CURRENCY_GENERATOR`, включая локализованные имена.
- `structure_names_unmatched.csv` — записи, для которых не найдено надёжного ключа названия в секции `STRUCTURE` локализаций.
- `resource_ids_catalog.csv` — найденные символьные ключи ресурсов и локализованные имена EN/RU.

## Как сопоставлялись имена
Названия построек взяты из секции `STRUCTURE` английской и русской runtime-локализаций.
- `EXACT_ID_MATCH`: внутренний ID записи совпадает с ключом локализации.
- `ALIAS_KEY_MATCH`: для некоторых новых генераторов использован найденный альтернативный ключ локализации с теми же признаками события/объекта.
- `NO_LOCALIZATION_KEY`: точное имя в доступных локализациях не найдено; ячейки имени оставлены пустыми, угадывания не подставлялись.

Итоги по постройкам: 954 записи; 891 точное совпадение; 6 совпадений по проверенным alias-ключам; 57 записей без найденного имени. Некоторые alias-ключи локализованы неполно; смотрите поле `Name match` и `Localization key used`.

## Каталог ресурсов: важное различие
`resource_ids_catalog.csv` содержит символьные ключи игровых ресурсов (например, `GOLD`, `FOOD`, `GEM`, `DUNGEON_TOKEN`) с отображаемыми именами. Для `GOLD`, `FOOD` и `XP` ключи также встречаются как `RESOURCE_ID.BASE_ID` в конфигурации наград.

В проверенных статических конфигурациях не обнаружена отдельная таблица с числовыми UID валют и расходуемых ресурсов, поэтому столбец `NUMERIC_UID` оставлен пустым намеренно. Не подставляйте вместо него `GLOT_ID` (ID аналитики/телеметрии) или UID постройки-генератора: это другие сущности. Для поиска числовых ID ресурсов потребуется трассировка работающего процесса DragonML через инвентарные/ресурсные методы.

## Важное различие для построек
`UID` — числовой идентификатор записи постройки, `ID` — внутреннее строковое имя, а `Display name EN/RU` — отображаемое имя из локализации. `MESHES` содержит имена моделей, не имена построек.
