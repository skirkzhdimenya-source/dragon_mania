# Каталог построек Dragon Mania Legends / DragonML

Источник: извлечённый из игрового каталога `files/data/structures.json`.

## Файлы
- `structures.json` — оригинальные 954 записи без потери полей.
- `structures_catalog.csv` — полный табличный каталог с UID, внутренним ID, параметрами и локализованными именами EN/RU.
- `event_generators.csv` — все 158 записей с `OBJECT_TYPE = EVENT_CURRENCY_GENERATOR`, включая локализованные имена.
- `structure_names_unmatched.csv` — записи, для которых не найдено надёжного ключа названия в секции `STRUCTURE` локализаций.

## Как сопоставлялись имена
Названия взяты из секции `STRUCTURE` английской и русской runtime-локализаций.
- `EXACT_ID_MATCH`: внутренний ID записи совпадает с ключом локализации.
- `ALIAS_KEY_MATCH`: для некоторых новых генераторов использован найденный альтернативный ключ локализации с теми же признаками события/объекта.
- `NO_LOCALIZATION_KEY`: точное имя в доступных локализациях не найдено; ячейки имени оставлены пустыми, угадывания не подставлялись.

Итоги: 954 записей; 891 точных совпадений; 6 совпадений по проверенным alias-ключам; 57 записей без найденного имени. Некоторые alias-ключи локализованы неполно (например, отдельная русская строка может быть на другом языке); смотрите поле `Name match` и `Localization key used`.

## Важное различие
`UID` — числовой идентификатор записи, `ID` — внутреннее строковое имя, а `Display name EN/RU` — отображаемое имя из локализации. `MESHES` содержит имена моделей, не имена построек.
