# Каталог построек Dragon Mania Legends / DragonML

Исходная база: извлечённый игровой файл `structures.json` из пути `files/data/structures.json`.

## Файлы
- `structures.json` — полная исходная таблица структур, без потери исходных полей.
- `structures_catalog.csv` — все записи в табличном формате, включая UID, внутренний ID, тип, модели, DLC, ограничения и исходный JSON.
- `event_generators.csv` — фильтр по `OBJECT_TYPE = EVENT_CURRENCY_GENERATOR`.

## Примечания
- `UID` — числовой UID записи в конфигурации; `ID` — внутренний строковый идентификатор. Это разные поля.
- `MESHES` — имена моделей, а не обязательно отображаемые игровые названия.
- В полной таблице присутствуют игровые постройки, жилища, генераторы валюты событий, декорации и препятствия; «все структуры» не означает, что каждая запись доступна для покупки.
- Реальные локализованные имена будут сопоставлены отдельно с секцией `STRUCTURE` файлов локализации, где совпадения надёжны.
